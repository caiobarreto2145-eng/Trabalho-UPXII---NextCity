# EcoPontos – Entrega Final (UPX II – NextCity)

Plataforma web gamificada de sustentabilidade: o usuário registra ações sustentáveis, ganha pontos, troca por recompensas (vouchers) e aparece no ranking.

**Equipe NextCity:** Caio Nascimento, Kevin Brisola, Murilo Marigo, Pietro Oliveira e Vitor Henrique
**Orientadora:** Profa. Brenda Medina de Oliveira – Centro Universitário Facens
